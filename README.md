MediaTracker is a desktop application for organizing and tracking movies, TV series, and books. It allows users to maintain a personal wishlist, record watch or reading dates, and manage details like franchises, seasons, authors, and notes. 

The app features a card-based UI with dark mode support, inline editing, and collapsible sections for easy navigation.

**Features:**

- **Add, edit, and remove media**: Quickly manage movies, series, and books with editable cards.

- **Colored item cards**: Assign a specific color to each item card individually. Movies with the same franchise share the same color.

- **Track progress**: Store watch dates or reading sessions for each item.

- **Wishlist grouping**: Organize items by movie, series, or books automatically.

- **Dark mode support**: Dynamic card colors and UI adjustments for comfortable viewing.

- **Favorites and comments**: Mark favorite items and add notes or comments.

- **Validation & duplicate prevention**: Ensures correct input and prevents repeated entries.

- **Search bar**: Allows to quickly search for a specific title, saga, marked as favorite, franchise, or author.
